# Product Evolution Roadmap V1.1

- 状态：Draft
- 日期：2026-08-15
- 平台：Historical Persona OS

## 1. 路线原则

产品扩展遵循“先建立可靠知识底座，再抽取经验；先验证方法，再扩展人物；先保证质量，再扩大数量”的原则。

扩展顺序不由人物知名度决定，而由以下因素共同决定：

- 方法论验证需要
- 用户真实问题
- 资料与史料质量
- Knowledge Layer 完整度
- Experience Package 可构建程度
- 推荐引擎所需的经验多样性
- 内容传播效果
- 安全与伦理可控性

## 2. Phase 1：帝王系列 V1

目标：在 History First 架构下验证 Historical Persona OS 的完整方法。

第一位 Gold Standard：唐太宗李世民。

本阶段重点不是先穷尽所有帝王，而是跑通：

```text
权威史料
→ Knowledge Layer
→ 历史事件与关系
→ Experience Extraction
→ Experience Matching
→ Persona Recommendation
→ Persona Runtime
→ Consultation Output
```

重点能力：

- 权威史料索引与来源治理
- Knowledge Layer 基础结构
- Historical Event / Relationship 结构
- Experience Package
- Experience Matching
- Evidence Chain
- Consultation Runtime
- Persona Recommendation
- 自媒体内容输出

唐太宗负责验证方法和质量标准；其他帝王先满足能够参与推荐的最小数据标准，再持续加深。

## 3. Phase 2：扩大中国历史人物范围

在帝王系列方法稳定后，可逐步讨论并扩展至：

- 名臣
- 思想家
- 军事家
- 教育家
- 文学家
- 商业人物

具体人物范围须经过 Persona Admission Standard 审核，不在本阶段预先列名单。

所有新增人物继续遵守 History First：先进入可靠资料，再抽取 Experience，再建立 Persona。

## 4. Phase 3：跨文化历史人物

引入世界历史中具有可验证人生经验和长期学习价值的人物。

重点验证：

- 不同文化的资料体系与证据标准
- 不同语言资料的来源治理
- 跨文化经验迁移
- 推荐引擎是否存在文化偏差

## 5. Phase 4：现代企业家与商业人物

在历史人格体系成熟后，引入企业家系列。

底层资料可包括：

- 自传与高质量传记
- 股东信
- 公开演讲
- 采访
- 公司档案
- 法庭或监管文件
- 可验证的重大决策记录

重点不是“成功学”，而是可验证经历，例如：

- 创业与失败
- 产品判断
- 组织扩张
- 被罢免与重返
- 长期投资
- 资本配置
- 危机管理

## 6. Phase 5：思想家、科学家、教育家等专业系列

逐步扩展到：

- 思想家系列
- 科学家系列
- 教育家系列
- 艺术家系列
- 其他经审核的人物类别

这些系列需要针对专业知识边界增加额外约束，避免把人物历史经验误当作现代专业结论。

## 7. 产品形态演进

### Stage A：内容生产引擎

由运营者预设真实人生问题，系统先检索相关经验，再推荐人物并生成经审核的历史经验分析，用于视频、文字和音频内容。

### Stage B：用户自主咨询

用户自行提问，系统完成问题分析、历史检索、Experience Matching、人物推荐和经验型咨询。

### Stage C：多人物比较

同一问题可由多个具有不同相关经验的人物回答，用户比较不同人生路径。

### Stage D：个人长期智慧档案

系统保存用户长期问题、听过的人物观点、自己的反思与最终决策，形成个人决策与成长记录。

### Stage E：多模态数字人格

通过语音、半身互动影像和环境表现增强人物在场感，但数字人始终是经验证 Experience 与 Persona 的表达层。

## 8. 自媒体与平台共同演进

自媒体不是单纯获客渠道，而是：

- 问题发现器
- 产品验证器
- 历史经验匹配测试场
- 受众研究渠道
- 人物推荐效果观察渠道

第一阶段先预设问题、向不特定大众传播，再根据真实观看、评论、分享和提问逐步识别稳定受众。

## 9. 当前里程碑不变

当前项目里程碑仍为：

- 下周五前完成可运行的帝王智库 V1；
- 回答者建设优先集中力量完成唐太宗 Gold Standard；
- 平台能力与帝王最小推荐画像并行推进；
- 周末进入首期视频录制。

History First 架构调整不得成为延迟该里程碑的理由；所有本周实施工作应优先服务于这条端到端链路。

## 10. 不做的事情

平台不以以下目标驱动扩展：

- 快速堆积名人数量
- 追逐热点人物而降低资料标准
- 先塑造人物观点、后寻找史料证明
- 制造全知全能的人格
- 用人物崇拜替代独立判断
- 将历史经验包装为唯一答案

## 11. 长期愿景

> 形成一个覆盖古今中外、以可靠资料为底座、以可追溯人生经验为核心、能够帮助现代人找到相关历史经验、理解不同人生路径并形成自己判断的人类经验智慧平台。
