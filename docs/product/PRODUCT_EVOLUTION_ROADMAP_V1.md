# Product Evolution Roadmap V1.0

- 状态：Draft
- 日期：2026-08-15
- 平台：Historical Persona OS

## 1. 路线原则

产品扩展遵循“先验证方法，再扩展人物；先保证质量，再扩大数量”的原则。

扩展顺序不由人物知名度决定，而由以下因素共同决定：

- 方法论验证需要
- 用户真实问题
- 史料与资料质量
- Experience Package 可构建程度
- 推荐引擎所需的经验多样性
- 内容传播效果
- 安全与伦理可控性

## 2. Phase 1：帝王系列

目标：验证 Historical Persona OS 的完整方法。

第一位样板：唐太宗李世民。

后续帝王应刻意选择与唐太宗经验结构和人格风格差异明显的人物，以验证系统是否真正可复制。

重点能力：

- Persona Runtime
- Experience Package
- Experience Matching
- Evidence Chain
- Consultation Runtime
- Persona Recommendation
- 自媒体内容输出

## 3. Phase 2：扩大中国历史人物范围

在帝王系列方法稳定后，可逐步讨论并扩展至：

- 名臣
- 思想家
- 军事家
- 教育家
- 文学家
- 商业人物

具体人物范围须经过 Persona Admission Standard 审核，不在本阶段预先列名单。

## 4. Phase 3：跨文化历史人物

引入世界历史中具有可验证人生经验和长期学习价值的人物。

重点验证：

- 不同文化的价值观表达
- 不同资料体系的证据标准
- 跨文化经验迁移
- 推荐引擎是否存在文化偏差

## 5. Phase 4：现代企业家与商业人物

在历史人格体系成熟后，引入企业家系列。

重点不是“成功学”，而是可验证经历，例如：

- 创业与失败
- 产品判断
- 组织扩张
- 被罢免与重返
- 长期投资
- 资本配置
- 危机管理

## 6. Phase 5：思想家、科学家、教育家等专业系列

逐步扩展到：

- 思想家系列
- 科学家系列
- 教育家系列
- 艺术家系列
- 其他经审核的人物类别

这些系列需要针对专业知识边界增加额外约束，避免把人物历史经验误当作现代专业结论。

## 7. 产品形态演进

### Stage A：内容生产引擎

由运营者预设真实人生问题，系统生成经审核的历史经验分析，用于视频、文字和音频内容。

### Stage B：用户自主咨询

用户可以自行提问，由系统推荐合适人物并进行经验型咨询。

### Stage C：多人物比较

同一问题由多个具有不同经验结构的人物回答，用户比较不同人生路径。

### Stage D：个人长期智慧档案

系统保存用户长期问题、听过的人物观点、自己的反思与最终决策，形成个人决策与成长记录。

### Stage E：多模态数字人格

通过语音、半身互动影像和环境表现，增强历史人格的在场感，但数字人始终是 Experience Persona 的表达层。

## 8. 自媒体与平台共同演进

自媒体不是单纯获客渠道，而是：

- 问题发现器
- 产品验证器
- Experience Package 测试场
- 受众研究渠道
- 人物推荐效果观察渠道

第一阶段先预设问题、向不特定大众传播，再根据真实观看、评论、分享和提问逐步识别稳定受众。

## 9. 不做的事情

平台不以以下目标驱动扩展：

- 快速堆积名人数量
- 追逐热点人物而降低资料标准
- 制造全知全能的人格
- 用人物崇拜替代独立判断
- 将历史经验包装为唯一答案

## 10. 长期愿景

> 形成一个覆盖古今中外、以可靠证据为基础、以人生经验为核心、能够帮助现代人比较不同人生路径并形成自己判断的人类经验智慧平台。
