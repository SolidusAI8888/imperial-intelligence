# Platform Vision V1.1

- 状态：Draft
- 日期：2026-08-15
- 底层平台：Historical Persona OS
- 第一阶段产品：帝王智库 Imperial Intelligence

## 1. 平台长期定位

Historical Persona OS 的长期目标，不是建设一个“名人聊天机器人”集合，而是建设一个以可靠资料为基础、可验证、可解释、可持续扩展的人类经验智慧平台。

平台希望把古今中外具有持续学习价值的人物人生记录与经验，组织成可被现代用户检索、请教、比较和反思的智慧体系。

核心原则：

> 不是向名人索取答案，而是向经过时间与实践检验的人生经验请教。

## 2. History First：历史资料是底层资产

平台正式采用 History First 架构。

权威史书、原始文献、考古材料、高质量传记及研究资料，是平台的底层知识资产。人物、Experience、Persona 与 Consultation 都是从这些资料中派生出的上层结构。

核心数据流为：

```text
权威资料
→ Knowledge Layer
→ 历史事件与人物关系
→ Experience Layer
→ 问题与经验匹配
→ Persona Selection
→ Persona Layer
→ Consultation
→ 参考意见与启发
→ 用户自行决定
```

系统永远不是先寻找“最合适的名人”，而是先寻找“最相关、最可信、最可迁移的人生经验”。人物是这些经验的第一人称表达者。

## 3. 第一阶段：帝王系列

帝王系列是平台的第一阶段验证集。

第一位标准样板为唐太宗李世民。

帝王系列承担三项任务：

1. 验证“史料 → 事件 → 经历 → 思考 → 行动 → 结果 → 经验 → 现代迁移 → 参考建议”的方法论；
2. 验证 Historical Persona OS 能否在不同人物之间保持可复制性；
3. 为自媒体内容与后续交互产品提供第一批高质量内容资产。

唐太宗是 Gold Standard，用于验证完整数据链和表达质量；其他帝王用于验证推荐、匹配和复制能力。

## 4. 后续人物系列

在帝王系列验证完成后，平台可逐步扩展至：

- 企业家系列
- 思想家系列
- 科学家系列
- 教育家系列
- 军事家系列
- 艺术家系列
- 外交家系列
- 其他具有明确人生经验价值的类别

具体扩展顺序不由人物知名度决定，而由产品验证、用户需求、资料质量和经验可迁移性共同决定。

## 5. 平台真正组织的对象

平台的核心资产不是人物传记本身，而是可追溯的知识与经验结构：

- Sources：权威资料与原始来源
- Passages：原文片段
- Historical Claims：历史主张
- Historical Events：可验证历史事件
- Relationships：人物关系
- Experience Packages：可复用人生经验
- Experience Profiles：人物经验画像
- Persona Packages：人格与人生阶段模型
- Evidence Chains：史料、推断、反证与审核链路

人物身份是经验的载体和表达者，而不是平台价值的终点。

## 6. 平台价值主张

平台不承诺替用户做决定。

平台提供：

- 历史上与问题最相关的人和事件；
- 相关人物曾经历过什么；
- 当时如何理解问题；
- 如何行动；
- 产生了什么结果和代价；
- 哪些经验可以迁移到今天；
- 哪些部分不能直接迁移；
- 如果站在用户处境中，该人物可能会如何思考。

最终决定权始终属于用户。

## 7. 问题优先，而非人物优先

第一阶段的用户入口应优先是现实问题，而不是人物选择页。

标准流程：

```text
用户提出问题
→ Question Analysis
→ 历史检索
→ Experience Matching
→ 推荐回答人物
→ 历史经验型回答
```

若用户明确指定某个人物，系统尊重用户选择，但仍必须说明该人物是否拥有足够相关的经验。

## 8. 冷启动策略

第一阶段不预设狭窄受众，而优先围绕真实、普遍、反复出现的人生问题生产内容，例如：

- 要不要辞职；
- 是否继续一段关系；
- 是否原谅背叛；
- 是否继续坚持；
- 是否值得冒险；
- 如何面对失败；
- 如何处理信任与冲突。

自媒体内容是第一阶段的公共产品界面，也是验证用户需求、问题结构、经验匹配和人物推荐的重要渠道。

## 9. 平台使命

> 把人类历史上具有持续学习价值的可靠人生记录，转化成现代人可以检索、理解、比较、反思和借鉴的经验智慧资源。
