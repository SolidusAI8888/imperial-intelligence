# 帝王智库 Cold Start Content Strategy V1.0

- 状态：Draft
- 日期：2026-08-15
- 产品：帝王智库 Imperial Intelligence

## 1. 冷启动阶段不先定义精准目标用户

产品初期不假设已经知道“最适合帝王智库的人是谁”。

冷启动的现实路径是：

```text
创作者预设现实问题
→ 帝王智库基于历史经历讨论并输出
→ 制作视频或文字内容
→ 向不特定大众传播
→ 持续发布大量内容
→ 观察观看、停留、评论、转发和主动提问
→ 用户群体自然聚集
→ 再反向定义真实核心受众
```

因此，第一阶段不是“先找精准用户”，而是“先找真实问题”。

## 2. 第一阶段的直接受众

第一阶段受众可以是随机进入内容的普通人。

他们未必：

- 是历史爱好者；
- 是创业者；
- 是管理者；
- 有重大职业决策；
- 对 AI 技术感兴趣。

他们可能只是正处于某种现实迷茫或生活困境中。

例如：

- 上班很累，不想上了怎么办？
- 工作很累但钱很少，我该继续吗？
- 男朋友出轨了，我要不要继续和他在一起？
- 同事一直针对我，我要不要反击？
- 三十多岁还没有找到方向怎么办？
- 父母总想控制我的选择怎么办？
- 我该不该原谅背叛我的人？

内容首先必须让普通人觉得“这是我的问题”，而不是先让他们觉得“这是一个历史栏目”。

## 3. 目标问题优先于目标用户

冷启动阶段的核心研究对象是“问题池”。

问题应优先满足：

- 普通人能立即理解；
- 具有真实情绪张力；
- 没有简单标准答案；
- 历史人物确实存在可类比的人生经验；
- 不同历史人物可能给出明显不同的思考视角；
- 适合形成视频标题、开场冲突和讨论。

## 4. 永恒人生母题

大量表面不同的问题，可以归入较稳定的问题结构，例如：

### 去还是留

- 要不要辞职；
- 要不要分手；
- 要不要离开现在的城市；
- 要不要退出一个合作关系。

### 忍还是争

- 被同事针对；
- 被上级压制；
- 家庭边界受到侵犯；
- 受到不公平待遇。

### 信还是防

- 是否再次相信背叛过自己的人；
- 是否相信合作伙伴；
- 是否把重要事情交给别人。

### 得还是舍

- 高薪与快乐；
- 稳定与机会；
- 面子与现实利益；
- 眼前收益与长期价值。

### 坚持还是止损

- 已经投入很多的工作、关系或项目是否继续；
- 如何判断坚持是毅力还是沉没成本。

未来应建立“永恒人生问题库”，而不是无结构地堆积无数随机问题。

## 5. 自媒体与产品的关系

冷启动阶段：

- Historical Persona OS 是底层引擎；
- 帝王智库是历史人格咨询能力；
- 自媒体栏目是大众最先接触到的产品形态；
- 创作者是问题选择者、主持人和现代语境解释者。

自媒体不是简单广告渠道，而是产品验证与用户研究机制。

每一期内容都可以帮助验证：

- 什么问题能够吸引用户；
- 哪个历史人物更有共鸣；
- 哪种经历讲述方式更可信；
- 哪些历史经验真正能启发现代用户；
- 用户接下来还想问什么。

## 6. 用户画像应由真实行为长出来

在持续发布足够多内容之前，不急于给受众贴固定标签。

后续根据真实数据观察：

- 谁在观看；
- 谁会看完；
- 谁会收藏和分享；
- 谁会在评论区讲自己的处境；
- 谁会主动提出下一个问题；
- 谁最终愿意进入帝王智库自己咨询。

真实用户画像应由这些行为反推，而不是在冷启动阶段凭想象确定。

## 7. 内容的核心承诺

每一期内容不是“古人教现代人做人”。

而是：

> 面对一个今天仍困扰普通人的问题，看看一位真实历史人物曾经如何经历、如何权衡、如何行动、付出过什么代价，以及这些经验能否给今天的我们一个新的思考角度。

## 8. 创作者角色

创作者本人不能从内容中消失。

建议结构：

```text
创作者提出真实问题
→ 说明为什么请教某位历史人物
→ 历史人格回顾自身经历并给出参考
→ 创作者补充现代背景、差异或个人观察
→ 把思考和决定留给观众
```

长期品牌价值不只是“AI 帝王”，还包括创作者选择问题、组织讨论、解释历史与现代差异的能力。
