# Source verification note — CN-QING-0002

The acquisition manifest uses the Wikisource title `欽定大清會典 (四庫全書本)` and the numbered-volume pattern `/卷NNN`. Public pages for at least `卷034` and `卷100` are available with revision histories, which is sufficient to route this edition through the existing numbered-volume extractor. The project treats the 100-volume Siku edition as one verified edition of the broader 大清會典 source family.
