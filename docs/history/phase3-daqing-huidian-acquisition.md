# Phase 3 — 大清會典 acquisition

`CN-QING-0002` is now anchored to the verified 100-volume `欽定大清會典 (四庫全書本)` edition exposed by zh.wikisource.org. The numbered-volume ingestion path can therefore archive this edition using the existing extractor-v3 canonical text/provenance pair format.

Completion semantics are edition-scoped. A successful 100-volume archive means this registered Siku edition is complete in the project corpus; it does not mean every historical Qing Huidian revision or later continuation has been acquired. Other editions or continuations must receive explicit edition metadata before they can expand the broader source family.
